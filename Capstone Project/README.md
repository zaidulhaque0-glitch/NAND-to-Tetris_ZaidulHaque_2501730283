# Capstone Project: Make the Computer Draw a Box

Nand to Tetris I (ETCCNT301) capstone submission files.

## Included files

- `CPU.hdl`, `Memory.hdl`, `Computer.hdl`: Project 5 hardware chips
- `assembler.py`: two-pass Hack assembler
- `Box.asm`: keyboard-controlled box program (64 pixels wide, 20 rows, beginning at row 83)
- `Box.hack`: assembled machine code for `Box.asm`

To assemble the program, run `python assembler.py Box.asm`.
